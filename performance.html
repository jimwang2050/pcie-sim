计算公式与计量边界
业务吞吐与方向占用
B = Σ 已交付业务字节 / Δt；ρℓ = 方向线上字节 / (Δt × Cℓ)。读以可消费、写以目标可见为准。
容量与资源上界
Cℓ = GT/s × Lane 数 / 8 × η。固定业务配比下，Bmax = minᵣ(Kᵣ × V / Dᵣ)；V 为总业务字节，Dᵣ 为总资源占用量 × ns，Kᵣ 为资源并行容量。方向链路、AXI、Tag、Credit 各自约束。
链路理想吞吐与达成率
Wℓ = Σ MRd 包字节 + Σ MWr 包字节 + Σ CplD 包字节；每包计载荷、头及本模型封包开销。Tℓ = Wℓ / Cℓ；各方向可并行，故 Bideal = V / maxℓ(Tℓ) = minℓ(Cℓ × V / Wℓ)。下表按本轮参数代入。
逐段递推与读 RTT
t出 = t到 + Q + L₀ + S / C + T切换。Q 为该段准入等待，L₀ 为管线或传播时延，S 为本段字节数。RTT首 = min(tCpl) − t₀，RTT末 = max(tCpl) − t₀；多片按完成时间取首末，不把并行路径时延叠加。
Tag 与写入
BTag ≈ NTag × 平均每笔 MRd 有效字节 / 平均 Tag 持有时间。持有时间从分配到回收，比链路 RTT 多计发前和接收处理。Posted MWr 单独计算提交到目标可见的延迟。
