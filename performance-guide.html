PCIe 系统性能实验室怎么读？

长图

答

结论

默认 Gen4 ×8、50:50、512 B 下，EP A → RP 链路先到瓶颈：整批交付 17.6 GB/s，是链路理想 27.3 GB/s 的 64%；首片 RTT 310.7 ns，其中 DDR 服务 111 ns，占 35.7%。

  1. 去程字节更多：每 1024 B 业务要发 584 B（24 B MRd + 2×280 B MWr），返程只回 552 B CplD。
  2. 资源上界与链路理想同为 27.3 GB/s，默认配置没有更紧的 Tag、AXI 或 Credit 约束。
  3. RTT 的最大单跳是目标 DDR 服务 111 ns，占首片 35.7%。
  4. 改 Gen、读写比或节点带宽都会换瓶颈，需要用同一套口径重跑。

适用于Gen4 ×850:50512 B128 笔默认模型参数未校准

1

主路径经过哪些模块？

图的结构
  • CPU / DMA cpu
  • CMN / CHI cmn
  • Root Complex root
  • EP A ep
  • Host DDR hostmem
  • EP HBM epmem
  • cpu → cmn · CHI
  • cmn → root · AXI
  • root → ep · PCIe ×8
  • cmn → hostmem · DDR
  • ep → epmem · HBM

Root Complex 是合并节点，内部含 RC Bridge、RP CTL 与 RP PHY；EP A 同样合并了 EP PHY、EP CTL 与 AXI Fabric。

2

首片 RTT 花在哪？

首片 310.7 ns = 去程 79.0 + 目标 111.0 + 回程 120.7；末片再加尾片 17.7 ns，得到 328.4 ns。尾片是两片 CplD 的间隔，只影响末片，不进入首片。

3

带宽被哪条方向限制？

每条链路方向单独计费。EP A → RP 方向占用 64.4%，RP → EP 方向 60.9%；整批交付 17.6 GB/s 还包含启动与排空，因此低于链路理想 27.3 GB/s。
