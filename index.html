    说明

    时间轴按 1:100 压缩：Detect 的规范计时 12 ms 在此显示为 120 µs。

    Gen6 强制 Flit 模式（256B Flit、1b/1b PAM4）；Gen1–5 默认 Non-Flit，可在“模式”中切换对比。

    “LTSSM 电源管理”场景演示 L0s / L1.0–1.2 / L2（FTS、CLKREQ#、Beacon 唤醒），并包含热插拔：PRSNT# → 槽位上电 → PERST# 释放 → 训练 → DLLSC / 热插拔中断 → 安全拔出。

    “PHY 电气与均衡”场景演示 REF CLK/PLL、CDR 锁定、Equalization 收敛与 COM/眼图变化。

    顶栏「典型模型」提供 EQ / CDR / REF CLK+PLL 的建模假设与动态演示，以及 PM 电源管理模型（L / D / P 状态、平台 / RP / EP 架构、CLKREQ# / Beacon / WAKE# 唤醒）与 RAS 可靠性模型（错误检测 → 分级 → 上报 → 隔离 → 恢复，含 AER / DPC / EDR / FLR / 热插拔）。

    “Gen6 Flit 深入”场景演示 256B 布局与预设故障/重传流程；不执行标准 FM 编码或 CRC/FEC 算法。

    “Loopback / BERT”提供 Internal（器件内部）与 External（经通道）两套独立环回配置，顶栏选择后一次只运行一种，可分别选择 PRBS7/9/11/15/23/31 图案。

    “设备枚举”场景演示 CfgRd0 / CfgWr0、BAR 探测/分配与 Memory Space 使能。

    “内存读/写”场景演示 MRd→CplD、Posted MWr、流控信用与 UpdateFC。

    “MSI / MSI-X”与“AER”场景演示中断消息与错误上报。

    “DPC + RP PIO”场景演示下游端口隔离、Egress Control 与 RP PIO 错误终止（Fatal/Non-Fatal → 触发 DPC；Advisory → 仅记录并返回全 1）。

    “ATS + PRI”场景演示 Translation Request / ATC 命中、Invalid Request、Invalidate 与 Page Request / PRG Response。

    “PM D/P 状态”场景演示 D0–D3cold、P0–P2、PMCSR 与 PME 唤醒。

    单步时自动浮窗跟随当前 LTSSM 状态；选中其他行则跟随该行最新事件。

    速度支持 -32× ~ 2×：负号表示慢放（如 -4× 为 1/4 速）。

    单击左侧 LTSSM 状态可查看定义、进入/退出条件与物理意义。

    快捷键：空格 运行/暂停 · → 单步 · ← 后退 · R 复位 · Esc 关闭弹窗。
